# Provincial Health Office (PHO) Website

This repository contains the source code for the Provincial Health Office (PHO) Website and Content Management System (CMS). The platform is designed to provide public health information, a directory of provincial hospitals, health programs, and related services to the community.

## Features

- **Public Information Portal**: Pages detailing health programs, laboratory services, and hospital directories.
- **Content Management System (CMS)**: Integrated with Supabase to allow authorized personnel to dynamically update hospital information, services, and activities without altering the source code.
- **Responsive Design**: Built using modern web standards (HTML, CSS, JavaScript) to ensure accessibility across desktop and mobile devices.
